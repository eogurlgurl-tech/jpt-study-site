JPT 초보 전용

JPT 10주 완성 웹페이지

세로로 계속 내려보는 자료집 구조 대신, 필요한 내용만 바로 들어가서 볼 수 있게 다시 정리한 버전입니다. 기초, 문자표, 단어, 듣기, 문제, 마무리를 나누어 두었습니다.

홈 기초 문자표 단어·회화 듣기 문제·마무리

처음 들어왔을 때 제일 먼저 보는 화면입니다. 오늘의 표현과 10주 흐름만 빠르게 보고 다음 페이지로 넘어가면 됩니다.

오늘의 표현

もう一度お願いします。
읽는 법: もう いちど おねがいします
한글식 발음: 모- 이치도 오네가이시마스
뜻: 한 번 더 부탁합니다.
쓰는 상황: 상대방 말을 못 들었을 때, 다시 말해 달라고 할 때 자주 씁니다.

10주 전체 로드맵

1주차

글자와 소리 익히기

히라가나, 가타카나를 완벽히 외우기보다 자주 보이는 글자를 먼저 익힙니다.

2주차

조사 붙이기

は / を / に / で를 실제 예문에 붙여보면서 문장 구조를 익힙니다.

3주차

기본 동사 20개

갑니다, 먹습니다, 봅니다처럼 자주 나오는 동사를 문장째 익힙니다.

4주차

숫자와 시간

1시, 2시, 오늘, 내일, 어제처럼 점수로 이어지는 표현을 먼저 익힙니다.

5주차

생활 단어 확장

학교, 회사, 역, 전화, 예약, 회의 같은 생활 단어를 묶어서 봅니다.

6주차

부정 표현

ません, ない, まだ처럼 뜻을 반대로 만드는 표현을 익힙니다.

7주차

짧은 회화

일상 문장을 통째로 외워서 바로 반응할 수 있게 만듭니다.

8주차

문제 패턴 연습

조사, 시간, 부정, 장소처럼 자주 나오는 시험 유형만 집중합니다.

9주차

오답 정리

자꾸 틀리는 조사와 시간을 모아 짧게 복습합니다.

10주차

실전 감각 만들기

한 번에 오래 하기보다 짧게 자주 반복해 시험 감각을 만듭니다.

문장 뼈대와 시험에서 바로 쓰이는 핵심 문형만 모았습니다. 완전 초보라면 이 페이지를 제일 자주 보면 됩니다.

기본 문형

これは本です。

읽는 법: これは ほん です
한글식 발음: 코레와 혼 데스
뜻: 이것은 책입니다.

学校に行きます。

읽는 법: がっこう に いきます
한글식 발음: 각코- 니 이키마스
뜻: 학교에 갑니다.

水をください。

읽는 법: みず を ください
한글식 발음: 미즈 오 쿠다사이
뜻: 물 주세요.

明日は行きません。

읽는 법: あした は いきません
한글식 발음: 아시타와 이키마센
뜻: 내일은 가지 않습니다.

会議は三時からです。

읽는 법: かいぎ は さんじ から です
한글식 발음: 카이기와 산지 카라 데스
뜻: 회의는 3시부터입니다.

まだです。

읽는 법: まだ です
한글식 발음: 마다 데스
뜻: 아직입니다.

자주 나오는 조사

は

주어 뒤에 많이 옵니다.
예: わたしは学生です。

を

먹는 것, 보는 것 앞에 옵니다.
예: パンを食べます。

に

가는 곳, 시간 앞에 옵니다.
예: 学校に行きます。

で

행동하는 장소에 많이 씁니다.
예: 駅で会います。

の

소속, 연결 느낌입니다.
예: わたしの本です。

と

함께, 그리고 뜻으로 씁니다.
예: 友だちと行きます。

히라가나와 가타카나를 까먹었을 때 바로 확인하는 공간입니다. 발음도 함께 넣어 두었습니다.

히라가나 / 가타카나 한눈에 보기

자주 나오는 글자부터 익숙해지면 됩니다. 완벽 암기보다 자주 보면서 낯설지 않게 만드는 게 먼저입니다.

주차별 미니 테스트

1주차

がっこう 의 뜻은 무엇인가요?

정답: 학교
2주차

パン___食べます. 빈칸에 들어갈 조사는 무엇인가요?

정답: を
해설: 먹는 대상 앞에는 보통 を를 씁니다.
3주차

行きます 의 뜻은 무엇인가요?

정답: 갑니다
4주차

会議は三時からです. 에서 시간을 찾아보세요.

정답: 三時(3시)
5주차

えき 의 뜻은 무엇인가요?

정답: 역
6주차

行きません 은 갑니다 / 가지 않습니다 중 어느 뜻인가요?

정답: 가지 않습니다
해설: ません이 붙으면 부정입니다.
7주차

水をください. 의 뜻은 무엇인가요?

정답: 물 주세요.
8주차

金曜日は休みです. 에서 요일을 찾아보세요.

정답: 金曜日(금요일)
9주차

まだです. 는 완료 / 미완료 중 어느 쪽인가요?

정답: 미완료
해설: まだ는 아직, 아직 안 끝남의 느낌입니다.
10주차

駅で会います. 에서 장소를 나타내는 조사는 무엇인가요?

정답: で
해설: 행동하는 장소에는 보통 で를 씁니다.

시험 직전 요약

조사 빠르게 보기

は = 은/는
を = 을/를
に = 에, 시간
で = 에서
と = 와/과

꼭 기억할 표현

です = 입니다
ます = 합니다
ありません = 없습니다
行きません = 가지 않습니다

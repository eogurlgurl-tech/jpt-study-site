JPT 10주 완성 웹페이지

아이폰에서도 바로 보이고, 링크로 공유하기 쉬운 정적 웹 구조입니다. 기본 문형, 단어, 듣기, 문제, 10주 로드맵, 주차별 미니 테스트, 일상 회화 50문장, 듣기 문장 50개까지 한 번에 정리했습니다.

오늘의 표현

もう一度お願いします。
읽는 법: もう いちど おねがいします
한글식 발음: 모- 이치도 오네가이시마스
뜻: 한 번 더 부탁합니다.
쓰는 상황: 상대방 말을 못 들었을 때, 다시 말해 달라고 할 때 자주 씁니다.

10주 전체 로드맵

1주차

글자와 소리 익히기

히라가나/가타카나를 완벽히 외우기보다 자주 나오는 글자와 소리에 익숙해지기

2주차

조사 익히기

は / を / に / で / の를 실제 예문에 붙여 보기

3주차

기본 동사 ます형

行きます, 食べます, 見ます, 聞きます 중심으로 귀와 눈에 익히기

4주차

숫자와 시간

1시~12시, 今日 / 明日 / 昨日, から / まで에 반응하기

5주차

생활 단어 확장

장소, 회사, 학교, 교통, 음식, 예약, 회의 관련 기본 단어 늘리기

6주차

부정 표현

ません, ない, まだ 때문에 뜻이 바뀌는 문제 적응

7주차

짧은 문장 암기

일상 문장과 듣기 문장을 통으로 외우기 시작

8주차

기출형 문제 적응

조사 빈칸, 동사 변화, 시간, 짧은 안내문 문제에 빠르게 반응하기

9주차

오답 정리

안 들리는 문장, 자꾸 틀리는 조사와 시간 표현만 집중 복습

10주차

실전 마무리

새로운 내용은 줄이고, 반복 중심으로 시험장 감각 만들기

시간/동사 문제

会議は9時___始まります。 → から
店は10時___です。 → まで
きのう、映画を___。 → 見ました
あした、会社へ___。 → 行きます

부정/안내문 문제

今日は学校に___。 → 行きません
まだ宿題は___。 → できません
本日、休業します。 → 금일 휴업
入口はこちらです。 → 입구는 이쪽

회화형 문제

A: 何時ですか。 B: 2時___。 → です
A: 明日、来ますか。 B: いいえ、___。 → 来ません
A: これは何ですか。 B: ___本です。 → これは

시험 직전 요약

꼭 구분할 것

は = 은/는
を = 을/를
に = 에
で = 에서
の = 의

꼭 외울 끝말

です = 입니다
ます = 합니다
ました = 했습니다
ません = 하지 않습니다

자주 나오는 문장

学校に行きます。
水をください。
会議は三時からです。
明日は行きません。
まだです。
